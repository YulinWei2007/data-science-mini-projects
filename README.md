
# Data Science Mini-Project Portfolio

A collection of 14 self-directed data science projects covering statistical 
modeling, machine learning, data visualization, and NLP, built to strengthen 
practical skills alongside coursework.

## Projects

1. **Trends in High School GPAs** — exploratory analysis of GPA trends
2. **NWS Hourly Weather Forecast** — time-series data from the National Weather Service API
3. **Highest Mountains in the World** — data cleaning & visualization of global peak data
4. **US Congress** — analysis of congressional data
5. **Bechdel Test** — statistical analysis of film industry gender representation data
6. **Infinite Money in Roulette (Martingale)** — Monte Carlo simulation of the martingale betting strategy
7. **Choropleth Maps** — geographic data visualization
8. **FIFA Matches Since 1872** — historical sports data analysis
9. **Image Steganography** — hiding data within image files
10. **Chess and the Elo System** — statistical modeling of the Elo rating system
11. **Learning Handwritten Digits with AI** — image classification (MNIST-style) using machine learning
12. **Video Frame Scene Recognition Model** — computer vision / scene classification
13. **United Nations Refugee Data** — analysis of global refugee statistics
14. **AI vs. Human Response Analysis** — comparative analysis of AI-generated vs. human-generated text/responses

## Tools & Methods
Python, pandas, matplotlib/seaborn, scikit-learn, API data collection, 
Monte Carlo simulation, NLP, basic computer vision

## Notes
Each project is a self-contained Jupyter notebook (.ipynb) with its own 
data loading, analysis, and visualization.
